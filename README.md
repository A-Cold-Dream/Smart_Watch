# Smart_Watch
A smartwatch project based on STM32F411CEU6. The GUI is implemented with LVGL V9.4.0. It integrates MPU6050, blood oxygen, heart rate, temperature &amp; humidity, magnetometer and Bluetooth modules. Supports step counting, attitude calculation, environmental measurement, battery monitoring and Bluetooth data transmission.
The toolchain used in this project is STM32CubeMX + VSCode + CMake.
